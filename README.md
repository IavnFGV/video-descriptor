# Video Descriptor

Windows-приложение для работы с видео и аудио: расшифровка, участники,
конспект и статья с привязкой к исходной записи.

[Скачать / релизы](https://github.com/IavnFGV/video-descriptor/releases) ·
[История изменений](docs/development/history.md) ·
[Документация для разработки](docs/development/README.md)

## Текущее состояние

Версия Windows-пакета задаётся в [release-inputs.json](windows-app/release-inputs.json)
(сейчас **0.9.4**), номер сборки — в [BUILD](BUILD). Сборка и публикация выполняются
отдельно; доступные установщики и ZIP находятся в разделе «Релизы».
Основной вариант запуска — нативное приложение Windows x64.

- Распознавание Whisper с выбором NPU, GPU, CPU или режима «Авто».
- Разделение реплик по участникам и ручная правка текста, времени и имён.
- Пропуски распознавания видны в тексте и могут быть заполнены вручную;
  таймкоды модели не выдумываются.
- Конспекты и статьи через Ollama, LM Studio или Gemini.
  Модель по умолчанию задаётся в настройках; для отдельного действия можно
  выбрать другую модель или провайдера.
- Независимые версии расшифровок и материалов, сохранение готовых частей при
  сбое, Undo/Redo правок и экспорт SRT, VTT, TXT, Markdown и HTML.

## Начать работу

1. Скачайте Windows-установщик или ZIP из
   [Releases](https://github.com/IavnFGV/video-descriptor/releases).
   Готовому пакету не нужны Docker, WSL или отдельно установленный Python.
2. В настройках AI подключите имеющуюся модель Whisper либо подготовьте её
   из официального источника. Разделение по участникам подключается отдельно.
3. Добавьте видео или аудио, выберите параметры распознавания и запустите обработку.
4. Проверьте текст по записи, внесите правки и экспортируйте результат.
   Конспект и статья запускаются отдельными действиями. Перевод временно убран
   из интерфейса; [сохранённый backend и данные](docs/translation-providers.md) остаются.

Для локальных языковых моделей настройте внешний сервер:
[Ollama](docs/ollama-windows.md) или [LM Studio](docs/lmstudio-windows.md).
При выборе Gemini материал отправляется в облако Google.

## Модели и устройства

Публичные установщик и ZIP не содержат весов AI-моделей. Подходящие локальные
модели можно использовать повторно; скачивание выполняется с согласием пользователя.
Доступность NPU/GPU зависит от модели, runtime и драйвера. Приложение проверяет
готовность backend; явный выбор устройства не подменяется молча.

Локальные тесты и проверка установщика на Windows runner не заменяют проверку
на конкретном NPU/GPU и с выбранной языковой моделью.

to external CDNs are not needed.

  - License: `https://raw.githubusercontent.com/Ionaru/easy-markdown-editor/2.20.0/LICENSE`
- DOMPurify 3.4.16, Apache-2.0 OR MPL-2.0: https://github.com/cure53/DOMPurify/tree/3.4.16

  - License: `https://raw.githubusercontent.com/cure53/DOMPurify/3.4.16/LICENSE`

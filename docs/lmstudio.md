# Подключение LM Studio

LM Studio доступен как отдельный исполнитель перевода, конспекта и статьи. Ollama для этого подключения не требуется.

1. В LM Studio загрузите существующую языковую модель и включите Local Server.
2. В настройках Video Descriptor откройте **LM Studio · локальный сервер**. Адрес по умолчанию — `http://127.0.0.1:1234/v1`; можно указать другой локальный порт. Если сервер требует авторизацию, введите API-токен.
3. Сохраните подключение, затем нажмите **Проверить подключение и показать модели**. Укажите точный идентификатор модели для перевода и сохраните. В рабочем пространстве эти поля находятся в диалоге **Подключения**; для перевода выберите **Локально · LM Studio** и сохраните настройки перевода.
4. Для конспекта или статьи выберите **Локально · LM Studio** и модель в настройках соответствующего действия. Модель конспекта выбирается отдельно от переводчика.

Список моделей подтверждает доступ к серверу, но не успешную генерацию. Полная проверка выполняется при обработке: пустые и оборванные ответы отклоняются, перевод обязан сохранить метки исходных реплик. Исходная расшифровка сохраняется.

Устройство, GPU offload и загруженный контекст выбираются в LM Studio. Приложение не переключает устройство и не устанавливает/не запускает LM Studio, не скачивает модели. Автоматическое определение контекста требует native `/api/v1/models` с метаданными загруженного экземпляра. Если версия сервера не предоставляет эти данные, отключите автоматический контекст и задайте размер из настроек загрузки LM Studio вручную. План использует консервативную оценку размера текста; токенизатор не скачивается.

В Windows токен защищён DPAPI текущего пользователя; браузер получает только признак его наличия. Пустое поле сохраняет прежний токен. Для запуска из командной строки также поддерживается `LM_STUDIO_API_TOKEN`. Токен не попадает в задания, общий журнал и сохранённые payload запросов. Подключение разрешено только к localhost/127.0.0.1/::1 без credentials в URL.

При ошибке соединения проверьте, что Local Server включён, порт совпадает и авторизация настроена. При ошибке контекста проверьте загруженный размер, сократите предел ответа или используйте разбиение конспекта. Статья остаётся одним запросом по полной выбранной расшифровке.

Протоколы: [OpenAI-compatible API LM Studio](https://lmstudio.ai/docs/developer/openai-compat), [метаданные загруженных моделей](https://lmstudio.ai/docs/developer/rest/list).

# Редактор конспекта

Открывайте отчёт через `python -m video_descriptor.serve --port 8000`.
Видео, субтитры и расшифровка находятся слева, текст конспекта справа.
На узком экране блоки располагаются друг под другом.
Оглавление и описания разделов можно раскрыть нажатием на их заголовки;
по умолчанию они свёрнуты, чтобы сразу был виден текст конспекта.
Раскрытие разделов в просмотре запоминается в браузере. Переход к разделу
из оглавления автоматически раскрывает его. В редакторе Markdown остаётся полным.

## Работа с текстом

Над отчётом есть кнопка **Изменить название**. Введите своё название, например
«Лекция AWS»: заголовок станет `Лекция AWS [исходное-имя.mp4]`.
Имя видеофайла не меняется. Названия хранятся в `output/lecture-titles.json`,
общие для всех отчётов одного видео и сохраняются при обновлении интерфейса.
Ссылка **Все лекции** ведёт на главную страницу `/output/`, где видны эти названия.
Пустое название возвращает отображение исходного имени файла.

1. Нажмите **Редактировать**. Текст можно менять, дополнять и удалять как обычный Markdown.
   Панель помогает создавать заголовки, списки, ссылки и выделение.
2. Остановите видео в нужном месте и нажмите **+ Раздел в этом месте**.
   Появится заголовок вида `## [00:12:34] Новый раздел`: замените название и добавьте текст.
3. Заголовки с временем попадают в оглавление. Нажатие на время перемещает видео.
   Формат времени — `[ММ:СС]` или `[ЧЧ:ММ:СС]`.
4. В режиме редактирования рядом с разделами оглавления есть кнопка удаления.
   Она удаляет заголовок и текст до следующего заголовка того же или более высокого уровня.
   Кнопка **Отменить** возвращает удалённое.
5. Нажмите **Сохранить** или Ctrl/Cmd+S. Вкладка **Конспект** показывает оформленный текст.
   Кнопка **↓ Markdown** скачивает текущий текст, включая ещё не сохранённые изменения.

**Материал модели** содержит исходные разделы, заметки и раскрываемые источники:
можно сверяться с ними во время правки.

## Сохранение

Ваш текст хранится в `notes.user.md` рядом с конкретным `report.html`.
Перестроение отчёта и повторный анализ его не перезаписывают.
`notes.json`, `chapters.json` и исходный `notes.md` продолжают хранить результат модели;
редактирование в интерфейсе не меняет эти файлы.
У разных папок результатов, включая `off/` и `auto/`, отдельные пользовательские конспекты.

До первого сохранения редактор открывает подготовленный `editor-default.md`.
Браузер также сохраняет черновик в localStorage, чтобы восстановить незавершённую правку
после перезагрузки страницы. Это дополнительная защита, а не замена кнопки **Сохранить**.
Если файл изменился в другой вкладке, сервер отклонит сохранение устаревшей версии:
скачайте свои изменения и перечитайте страницу, чтобы объединить их вручную.
Черновик от другой версии файла можно скачать отдельно.

При открытии через `file://` или обычный статический сервер доступно редактирование
с выгрузкой Markdown, но сохранение в папку требует сервера `video_descriptor.serve`.

## Устройство и зависимости

Используется готовый редактор [EasyMDE](https://github.com/Ionaru/easy-markdown-editor)
2.20.0. [DOMPurify](https://github.com/cure53/DOMPurify) 3.4.16 очищает HTML предпросмотра.
Оба компонента поставляются локально в `video_descriptor/assets` и копируются в
`assets/` рядом с отчётом: CDN, npm-сборка и база данных для работы не нужны.
Лицензии лежат там же. Панель и предпросмотр настроены в `editor.js`, оформление
в `editor.css`, атомарное сохранение с проверкой версии — в `editor.py` и `serve.py`.

Чтобы обновить интерфейс старого результата без вызова модели:

```bash
python -m video_descriptor.translate "output/ПАПКА_РЕЗУЛЬТАТА" --refresh-only
```

После обновления перезагрузите страницу с Ctrl+F5. При замене библиотек обновляйте
локальные файлы и лицензии, затем проверяйте редактирование, сохранение, отмену удаления
и переход по времени в браузере.

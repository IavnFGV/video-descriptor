# Video Descriptor 0.9.4 — сборка 0012

## Что изменилось

- Меню «Вид» отображается только при открытой записи. В библиотеке, настройках
  и форме создания оно не занимает место; выбранные настройки сохраняются.
- Верхняя строка меню больше не меняет высоту при открытии пунктов, поэтому
  кнопки и содержимое окна остаются на месте.
- Номера новых сборок записываются с ведущими нулями, например `0012`. Благодаря
  этому файлы сборок удобнее располагать по имени в Проводнике.

## Обновление с предыдущей версии

- Сборка 11 не обнаружит сборку `0012` автоматически. Чтобы обновиться с неё,
  откройте страницу релиза и скачайте новый установщик вручную.

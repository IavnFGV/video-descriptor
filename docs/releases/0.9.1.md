# Video Descriptor 0.9.1 — Windows

Download `VideoDescriptor-0.9.1-windows-x64-setup.exe` to install the app,
or `VideoDescriptor-0.9.1-windows-x64.zip` to unpack and run it.
Docker and a system Python are not required for this Windows release.

## Changes

- Collapsible desktop sidebar: the topbar toggle hides or shows the navigation
  column, and the choice persists between app launches. When collapsed, the
  content expands to use the freed space.
- The recording workspace gets the same collapsible navigation, sharing the
  persisted sidebar state with the desktop shell.
- Standard Lucide panel-left close/open icons replace the previous chevron
  toggle in both surfaces.

## Initial setup

Whisper, community-1 and language models are not bundled in the installer or
ZIP. After installation, select the components you need and connect existing
models or download them from official sources through the app settings.
For the gated community-1 download, accept the Hugging Face terms and use your
own token. An already available local model does not require a re-download.
LM Studio is installed separately; enable its Local Server to connect it.

The dependent Silero VAD and test ONNX runtime samples are accounted for
separately: see `windows-app/THIRD-PARTY.md` and the included license notices.

## Checks and limitations

The published ZIP/EXE files are the same ones that passed acceptance;
checksums are in `SHA256SUMS.json` and the source commit is in
`acceptance-provenance.json`. Before publication the files are downloaded
again from GitHub and verified by SHA256. This workflow checks CPU scenarios
on a Windows runner. It does not confirm NPU/GPU hardware compatibility or the
behavior of a specific user model in LM Studio.

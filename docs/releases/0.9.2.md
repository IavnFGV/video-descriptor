# Video Descriptor 0.9.2 — Windows

Установщик: `VideoDescriptor-0.9.2-windows-x64-setup.exe`.
ZIP: `VideoDescriptor-0.9.2-windows-x64.zip`.
Docker и системный Python для Windows-приложения не требуются.

## Что изменилось

- Ollama и LM Studio используют общие настройки подключения: адрес сервера,
  проверка подключения, список доступных моделей и отдельный тест генерации.
  Для обоих провайдеров доступны инструкции по установке и подключению.
- «Модель по умолчанию» заранее подставляется для новых переводов, конспектов
  и статей. При запуске конкретного действия можно выбрать другую модель
  или провайдера. Устаревшее поле «Назначение» удалено.
- Задание сохраняет выбранные провайдер, адрес, модель и параметры генерации.
  Изменение общих настроек не перенаправляет уже поставленное в очередь или
  выполняющееся задание. Исчезнувшая модель вызывает понятную ошибку,
  другая модель или провайдер автоматически не подставляются.
- Ollama подключается как внешний сервер. Приложение не устанавливает,
  не запускает и не останавливает его, не скачивает модели автоматически.
  Существующий Gemini сохраняется.
- При непригодных таймкодах Whisper повторяет распознавание меньших частей
  проблемного участка. Неудача одного участка не скрывает оставшуюся запись.
  Инфраструктурные ошибки по-прежнему останавливают задание с сохранением
  готового результата. Отсутствующее время `end_ts=-1` не подменяется.
- Нераспознанные интервалы видны в расшифровке и отчёте. Их можно заполнить
  вручную обычным редактором реплик; сохранённый текст участвует в переводе,
  конспекте, статье и экспорте субтитров. Undo/Redo работает и для первого
  заполнения полностью нераспознанной записи. Такой результат не выдаётся
  за отсутствие речи.

## Установка и модели

Публичный standard-пакет не включает Whisper, community-1 и языковые модели.
После установки подключите имеющиеся модели либо получите их из официальных
источников с собственным согласием и доступом. Для необходимой загрузки
community-1 нужны условия Hugging Face и собственный токен; подходящая локальная
модель не требует повторного скачивания. Ollama и LM Studio устанавливаются
отдельно, устройство и контекст LM Studio настраиваются в самом LM Studio.

Ключи и токены не входят в снимки заданий и общий журнал. Для продолжения
старого задания с авторизацией может потребоваться восстановить доступ к
его исходному адресу сервера.

Domestic и cached offline пакеты предназначены для личного использования
и не публикуются. Учёт dependency assets и лицензий описан в
`windows-app/THIRD-PARTY.md`.

## Проверки и ограничения

При подготовке версии локальный Fast-набор прошёл: 749 тестов, 3 пропуска,
а также 25 CI-policy тестов. В изолированном браузере проверены ручное заполнение
пропусков, Undo/Redo, выбор независимых версий, вкладки материалов и редактирование
участников. Тесты LLM используют детерминированные HTTP-серверы, реальные Ollama
или LM Studio для них не требуются.

Проверка установщика на чистой Windows и public artifact gate выполняются
релизным workflow перед публикацией. Версия не считается опубликованной или
проверенной на реальном NPU/GPU только на основании локальных тестов.
Поведение конкретных моделей и аппаратная совместимость требуют отдельной
проверки. LM Studio сохраняет существующий режим ответа без streaming.

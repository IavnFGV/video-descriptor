# Video Descriptor 0.9.0 — Windows

Скачайте `VideoDescriptor-0.9.0-windows-x64-setup.exe` для установки приложения
или `VideoDescriptor-0.9.0-windows-x64.zip` для распаковки и запуска.
Docker и системный Python для этой Windows-поставки не требуются.

## Изменения

- Отдельная публикация Windows через GitHub Actions: проверка версии/коммита,
  сборка, воспроизводимость ZIP, проверки интерфейса, install/upgrade/uninstall
  и функциональная CPU-проверка с внешними тестовыми моделями.
- Подключение LM Studio для перевода, конспектов и статей.
- Сохранение подтверждённой готовности диаризации между запусками при неизменных входах.
- Защита от публикации личных Domestic/полных кешируемых пакетов и неизвестных весов.

## Первоначальная настройка

Whisper, community-1 и языковые модели не встроены в установщик или ZIP.
После установки выберите необходимые компоненты и подключите существующие модели
либо загрузите их с официальных источников через настройки приложения.
Для требующей доступа загрузки community-1 примите условия Hugging Face и используйте
собственный токен. Готовая локальная модель не требует повторного скачивания.
LM Studio устанавливается отдельно; для подключения включите его Local Server.

Зависимый Silero VAD и тестовые ONNX-примеры runtime учтены отдельно:
см. `windows-app/THIRD-PARTY.md` и включённые уведомления лицензий.

## Проверки и ограничения

Публикуются те же ZIP/EXE, которые прошли приёмку; контрольные суммы находятся
в `SHA256SUMS.json`, исходный commit — в `acceptance-provenance.json`.
Перед публикацией файлы повторно скачиваются с GitHub и сверяются по SHA256.
Этот workflow проверяет CPU-сценарии на Windows runner. Он не подтверждает
аппаратную совместимость NPU/GPU и работу конкретной модели пользователя в LM Studio.

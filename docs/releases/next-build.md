# Video Descriptor 0.9.4 — сборка 11 Windows

## Что изменилось

- Упрощено окно приложения: WebView2 занимает всю клиентскую область, а при потере
  связи доступен нативный экран ошибки с журналами и повторным подключением.
- Добавлено единое меню «Файл / Вид / Инструменты / Справка» и общие настройки
  подключений Ollama, LM Studio и Gemini для библиотеки и открытой записи.
- Рабочее пространство можно настроить через меню «Вид»: выбрать видимые панели
  и расположение видео и расшифровки. Настройки сохраняются между запусками;
  скрытие панели не удаляет материалы или несохранённые правки.
- Для выбранной расшифровки добавлено копирование исходного текста в буфер обмена.
- Настройки AI разделены на вкладки; подготовка компонентов находится в отдельной
  вкладке, а локальные серверы собраны в разделе «Локальный AI».
- Исправлена зависимость страницы справки Ollama в Linux CI.
- Исправлено сохранение контекста записи и несохранённого названия при переходе
  в настройки AI и обратно через новое меню.
- Исправлен сценарий приёмки установленной сборки для скрытых по умолчанию панелей
  и новой навигации. Локальная проверка на Windows требует проектное окружение .venv.

## Проверки и ограничения

- Для изменений, подготовленных к сборке 10, прошли Linux и Windows Fast CI;
  локальный Fast-набор на Windows завершился с результатом 840 passed, 3 skipped,
  кроме того прошли 29 проверок конфигурации.
- После исправлений сборки 11 локальный Fast-набор в проектном окружении завершился
  с результатом 841 passed, 4 skipped; локальная браузерная проверка сценария
  рабочего пространства прошла на тестовых данных.
- Предыдущая сборка 0.9.4-build.9 не опубликована: её проверка установленного
  приложения завершилась ошибкой. Сборка 0.9.4-build.10 также не опубликована:
  проверка установленного интерфейса завершилась ошибкой. Новая сборка должна
  отдельно пройти полную проверку установленного приложения и публикационные проверки.
- Эти проверки не подтверждают работу моделей на реальном NPU или GPU.

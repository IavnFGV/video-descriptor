# Video Descriptor — следующая сборка

## Gemini

- Вместо переключателя «Платный / Бесплатный» — одна галочка согласия на отправку
  данных в Google. Тариф и квоты определяет проект API-ключа. Сохранённый ключ
  вводить заново не нужно; если раньше был выбран платный режим, отметьте согласие
  один раз.
- Если Gemini временно недоступна (HTTP 503), приложение делает до двух
  автоповторов с фиксированной паузой 20 секунд перед каждым. Ошибки доступа и
  квоты показываются сразу, без повторов.
- В строке статуса конспекта или статьи через Gemini круговой таймер показывает,
  сколько секунд осталось до повтора. Здесь же можно включить повторы до остановки
  и выбрать модель для следующего запроса, в том числе для следующего повтора.
  Готовые части сохраняются, а модель по умолчанию не меняется. На узком окне
  элементы переносятся, не скрывая кнопку остановки.

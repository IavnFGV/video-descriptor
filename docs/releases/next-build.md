# Video Descriptor — следующая сборка

## Gemini

- Вместо переключателя «Платный / Бесплатный» — одна галочка согласия на отправку
  данных. Рядом объяснены различия условий Google. Тариф определяется проектом
  API-ключа; сохранённый ключ вводить заново не нужно.
- При временной недоступности Gemini (HTTP 503) запрос на генерацию конспекта или
  статьи автоматически повторяется до двух раз с паузой 20 секунд. Номер попытки виден в прогрессе
  и журнале. Повтор не запускает расшифровку заново; ошибки доступа и квоты
  показываются сразу.
- В строке статуса конспекта и статьи Gemini можно включить повторы HTTP 503
  до остановки и выбрать модель для следующего запроса. Круговой таймер показывает,
  сколько секунд осталось до повтора. Готовые части сохраняются,
  настройки действуют только на текущий запуск.

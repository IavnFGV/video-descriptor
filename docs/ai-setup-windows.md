# Первоначальная настройка AI в Windows

При первом запуске видна подсказка открыть настройки AI; принудительного перехода
нет. Откройте **Инструменты → Настройки AI**, выберите нужные функции и устройства,
затем явно подтвердите необходимые загрузки. Состояние подготовки сохраняется.
Необязательные компоненты можно пропустить. Для локальной расшифровки достаточно CPU, runtime,
Whisper и FFmpeg; Docker, Ollama, Gemini и диаризация не обязательны.

## Первый запуск

1. Посмотрите диагностику CPU, Intel GPU/NPU (Windows PnP), устройств OpenVINO,
   версий OpenVINO/GenAI, OCR и отдельных возможностей обработки. «Обнаружено»
   не означает «готово». PnP работает независимо от наличия OpenVINO.
2. Выберите папку уже скачанной **OpenVINO Whisper small FP16**. Проверка сверяет
   состав, конфигурацию и полный engine digest с проверенным профилем. Подключение
   сохраняет путь, не переносит и не удаляет исходную модель.
3. Либо раскройте предложение скачать этот профиль. До подтверждения показаны
   источник, revision, размер и требования. Отметьте согласие и нажмите скачать.
4. Выберите Auto (NPU → Intel OpenVINO GPU → CPU) или конкретное устройство.
   Нажмите **Подготовить распознавание** в панели готовности. Только успешная
   загрузка pipeline и проверка контракта worker дают состояние «Готово».
   Ручной выбор не подменяется. Intel OpenVINO GPU не означает NVIDIA CUDA.
5. При желании выберите WAV mono PCM16 / 16 кГц до 15 секунд и явно запустите
   короткую проверку. Файл отправляется только локальному worker; результат
   показывает устройство и число реплик. При отсутствии речи это явно сообщается.
6. Перейдите к обработке записи. Настройки модели, устройства и подготовки
   сохраняются после перезапуска.

Диагностика не запускает генерацию и не загружает ML pipeline. Проверка inventory
кэшируется; после изменения runtime/драйверов используйте **Обновить диагностику**.
Список моделей и health-check сервисов не является проверкой качества распознавания,
перевода или конспекта. FFmpeg отражён в общей панели диагностики; OCR/PnP отражают
обнаружение; готовность диаризации проверяется отдельно через менеджер компонентов.

## Загрузка Whisper с подтверждением

Этот раздел описывает downloader Whisper в SetupService. Подготовка отдельных
CPython/pyannote/community-1 также доступна через
[менеджер компонентов](ai-component-manager.md); это не единственная загрузка приложения.

Источник: [OpenVINO/whisper-small-fp16-ov](https://huggingface.co/OpenVINO/whisper-small-fp16-ov/tree/2410d022171ca8a97343182f88eec8807a324db9).
Revision: `2410d022171ca8a97343182f88eec8807a324db9`.
18 файлов, **493 208 911 байт (около 470 МиБ)**. SHA256 каждого файла записан
в `component-manifest.json`; происхождение проверено по Git blob IDs/LFS SHA256
этой revision. Итоговый engine digest остаётся
`b5566bca9ac6075e6da66fda6d8a582b00ff59b5e9322376a0b400639aecd809`.

Загрузка идёт в `windows-app/runtime/models/.whisper-small-<revision>.partial`.
Незавершённый файл имеет суффикс `.part`; размер ограничен манифестом, после загрузки
проверяется SHA256. Повтор сохраняет и повторно проверяет готовые файлы, незавершённый
файл начинает заново (HTTP Range не используется). После проверки всей модели
каталог атомарно переименовывается и подключается через существующий SetupService.
Готовая папка не перезаписывается, старые модели не удаляются. Архивы не распаковываются;
имена с путями, дисками и traversal отклоняются. Сбой оставляет настройки и проверенные
файлы на месте. Две подготовки/загрузки/смены модели и обработка записи защищены общей
блокировкой существующего ComputeManager. Закрытие backend во время загрузки может
прервать загрузку; после запуска повторите действие. Это не фоновый системный downloader.

## Ollama и Gemini

Ollama: следуйте [практической инструкции Windows](ollama-windows.md).
В настройках задайте endpoint, проверьте версию, обновите список `/api/tags`,
явно выберите модель, сохраните её и отдельно проверьте генерацию.
Приложение не устанавливает, не запускает и не удаляет Ollama и не скачивает модели.

Gemini: ключ, модель, режим оплаты и согласие для бесплатного проекта сохраняются
через прежние translation settings. Новое сохранение ключа на Windows использует
DPAPI текущего пользователя; секрет не возвращается API. Существующий открытый ключ
в старом JSON мигрирует при следующем сохранении. Скопированный на другую учётную запись
DPAPI-ключ потребует повторного ввода. Для перевода, конспекта и статьи провайдер
выбирается в настройках соответствующего действия; Ollama не обязателен при выборе
Gemini или LM Studio. Проверка доступа вызывает
только [Models API](https://ai.google.dev/api/models); она не подтверждает оплачиваемую
квоту генерации и не отправляет видео или транскрипцию. Тарифы и квоты определяются Google.

## Требования и проверки

Установщик/ZIP уже включает Python, FFmpeg и закреплённые OpenVINO/GenAI 2026.4.1.
Для запуска из исходников используется существующее окружение; мастер не создаёт venv.
Установщик подготавливает app-local WebView2 Runtime при отсутствии установленного;
для ZIP и source launch Runtime нужен отдельно. Драйверы Intel GPU/NPU, необязательные
Ollama/LM Studio и их модели пользователь устанавливает самостоятельно.
OCR/диаризация не блокируют CPU ASR.
Большие модели не включаются в installer и без согласия не скачиваются.

### Историческая проверка 18–19.10.2026 (desktop 0.7)

Реально на Windows 18.10.2026: CPU/OpenVINO Whisper small FP16, 10 секунд аудио,
1.33 с загрузки + 1.69 с inference, корректные таймкоды. Изолированный API-сценарий:
отсутствующая модель → подключение → подготовка CPU → probe → upload/ASR → SRT →
восстановление настроек. См. `verification-setup.json`, `verification-setup-cpu.json`.
Реальное окно WebView2 проверяет DOM/обработчики мастера и прежние tray/reconnect сценарии.
Дополнительно CPU inference проверен упакованным Python/OpenVINO из нового payload:
10 секунд аудио, 0.735 с загрузки + 1.75 с inference, корректные таймкоды; системный
Python/venv для этого запуска не использовался. Полный Python suite: 250 passed /
2 skipped, Ruff и pip check прошли.

Mock-тесты: потери сети, повтор загрузки, неверный hash, несовместимые модели,
PnP/runtime/model/readiness, Ollama offline и capabilities, отказ Gemini с редакцией
секрета, конкурентные операции, защита API, сохранение настроек и Auto/manual fallback.
DPAPI roundtrip проверяется настоящим Windows API, без mock.
Полная загрузка 470 МиБ по сети, реальная генерация Ollama/Gemini, OCR/диаризация,
новая аппаратная NPU/GPU-приёмка и новая чистая Windows VM в этой итерации не подтверждены.

Разработчику: `python -X utf8 windows-app/verify_setup.py --model <папка> --python <OpenVINO-python.exe> --audio <WAV>`.
Проверка не скачивает модели, не вызывает облако и запускает собственный CPU worker
на свободном порту; по завершении останавливает только этот процесс. Пользовательские
сервисы и исходная модель не меняются. Windows CI выполняет тесты мастера без больших
моделей и сохраняет прежние сборку ZIP, installer lifecycle и WebView2 smoke.

# Автоматическая подготовка AI — проверка feature

База: `main` / `0b4696e` (включая исправления XPU из PR #6).
Ветка: `feat/zero-configuration-ai`.

## Поведение

- При запуске открывается рабочий экран. Фоновый bootstrap использует сохранённое устройство и подключение; без скачивания, inference Ollama или запросов Gemini.
- Найденная модель подключается с проверкой SHA256, подготовка движка выполняется в фоне. Для отсутствующей модели есть «Скачать и подготовить» с источником и размером.
- Выбранное видео остаётся в форме во время подготовки.
- AI Settings состоят из свёрнутых native details; исходные controls, API, guards и диагностика сохранены.
- Диалог говорящих открывается из записи: Auto / Intel GPU / CPU, состояние и подготовка с Hugging Face consent. После успешной проверки исходное действие создаёт отдельную версию автоматически.
- Сохранённое действие ограничено workspace, отмена его очищает. Проверенные файлы и согласие с revision сохраняются.
- Для отсутствующего локального AI одна операция объединяет управляемую установку и загрузку модели. Внешняя остановленная Ollama автоматически не запускается.

## Необходимые согласия

1. Первая большая загрузка распознавания: источник и общий размер.
2. Первая установка окружения говорящих и загрузка community-1; условия Hugging Face и токен чтения, если требуется доступ.
3. Управляемая Ollama и выбранная языковая модель: источник и суммарный ориентировочный размер.
4. Облачный ключ, условия передачи данных и тариф Gemini — только явная настройка.
5. Запуск внешней остановленной Ollama и удаление управляемого окружения — отдельные явные действия.

При отказе подготовка не начинается. При старте приложения consent-диалоги не открываются.

## Действия пользователя (ожидаемый основной сценарий)

- Готовое распознавание: выбрать видео → «Расшифровать запись» (плюс переход «Новая запись», если открыта библиотека).
- Чистая установка: дополнительно «Скачать и подготовить» → одно подтверждение.
- Готовые говорящие: «Определить говорящих» → выбрать способ при необходимости → «Определить говорящих».
- Первая диаризация: дополнительно обязательные действия Hugging Face и согласие; установка/проверка/продолжение автоматические.

Это описание интерфейса; фактические E2E результаты и аппаратное покрытие фиксируются отдельно.
Merge и публикация релиза не выполняются автоматически.

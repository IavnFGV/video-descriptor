# Автоматическая подготовка AI — результаты

База: `main` / `0b4696e`, ветка `feat/zero-configuration-ai`, PR #8.

Приложение открывает рабочий экран, проверяет доступные компоненты в фоне и сохраняет выбранное устройство. При запуске нет загрузок моделей, inference Ollama или запросов Gemini. Настройки AI свёрнуты. Найденные модели проверяются и используются повторно.

Подготовка распознавания сохраняет выбранное видео. Встроенный диалог показывает источник и размер загрузки; отказ ничего не запускает. Диаризация доступна из записи с Auto / Intel GPU / CPU. Подготовка и проверка окружения автоматически продолжают исходное действие, создавая отдельную версию. Отмена очищает ожидающее действие, workspace изолированы. Проверенные файлы и revision согласия сохраняются. Управляемая Ollama устанавливается и загружает модель одной операцией; существующая служба используется без замены. Дополнительный каталог компонентов задаётся в расширенных настройках и применяется после перезапуска.

## Ограничения приёмки

- Новое получение gated-доступа Hugging Face и ввод нового токена не проверялись: использована ранее лицензированная community-1.
- Полная новая управляемая установка Ollama не проверена E2E; реальное подключение существующей службы проверено.
- Платные запросы Gemini не выполнялись.
- Последний встроенный HTML dialog загрузки и обновление индикатора подготовки прошли статические/контрактные проверки; полный сетевой E2E финальной сборки после этой UI-правки не повторялся.
- Offline inference и автоматическая проверка сохранённых настроек после перезапуска остаются без полного E2E подтверждения. Поэтому PR остаётся draft.

## Действия пользователя

Считаются смысловые действия, выбор файла считается одним действием:

- Готовое распознавание: «Новая запись» → выбрать видео → «Расшифровать» = 3, либо 2 из уже открытой формы.
- Чистая установка: дополнительно «Скачать и подготовить» и подтверждение = 5; принятых download confirmations — 1.
- Готовая диаризация: открыть диалог → запустить = 2; с выбором устройства — 3.
- Первое CPU окружение с уже лицензированной моделью: открыть диалог, CPU, согласие, запустить = 4. Новый доступ Hugging Face и токен требуют дополнительных действий.

## Где требуется явное согласие

Первая большая загрузка Whisper; установка окружения/модели говорящих с условиями Hugging Face; управляемая Ollama и её модель; настройка облачного ключа и передачи данных; запуск внешней остановленной службы и удаление управляемого окружения. При запуске приложения такие диалоги автоматически не открываются.

Merge и публикация релиза не выполнялись.

## Исправления после проверки пользователем — 0.8.1

Длинные сообщения компонентов переносятся внутри карточки; статус ошибки больше не дополняется старой причиной перехода на CPU. Предыдущее проверенное устройство подписано отдельно. В интерфейсе используются процессор (CPU), видеокарта (GPU), нейропроцессор (NPU); внутреннее API значение `xpu` сохранено. NPU для определения говорящих недоступен. Переключение с CPU на GPU требует подготовки отдельного окружения с согласием; проверка не запускается в заведомо CPU окружении.

367 tests passed, 2 skipped; дополнительно 21 CI-policy test. Реальный изолированный WebView2: 760×560, 1024×768, 1200×820, DPR 150%, без горизонтального переполнения. Для проверки длинной ошибки использована явно синтетическая DOM stress fixture: [отчёт](evidence/zero-configuration/device-ui.json), [скриншот](evidence/zero-configuration/settings-long-error.png). Это проверка layout, не доказательство установки AI. Проверка существующего пользовательского CPU runtime (`--doctor`) прошла. Новое незавершённое GPU окружение не содержит torch; причина прежней ошибки pip не сохранена старой версией. Новая версия различает этап установки пакетов и inference, но свежая установка GPU в рамках этой правки не выполнялась.

Дополнительно выполнено реальное определение говорящих на существующем CPU окружении и локальной модели: тестовая запись 9.14 с, результат содержит 3 корректных интервала; [отчёт](evidence/zero-configuration/cpu-0.8.1.json). Пользовательские настройки и окружения не изменялись.

## Однократная настройка — 0.8.2

После запуска видна подсказка открыть настройки; переход не принудительный. Вверху настроек выбираются нужные функции и устройства. Для GPU явно указано разрешение на загрузку. Пользователь отмечает общее согласие; для говорящих отдельно принимает условия Hugging Face и при первой загрузке вводит токен. Уже сохранённый токен и согласие с той же revision используются повторно.

Одна кнопка «Сохранить и подготовить» запускает backend очередь распознавание → говорящие → локальный AI (только выбранные функции). Можно уйти со страницы; UI показывает общий прогресс. Отмена останавливает текущий шаг и остаток. При ошибке готовые компоненты сохраняются. Внешний сервис Ollama должен быть подключён в соответствующем разделе; новая установка выполняется только в управляемом режиме. После закрытия приложения незавершённая очередь показывает повтор, не запускает новые загрузки молча.

Проверки: **378 passed, 2 skipped**, дополнительно **21 CI-policy test**. Покрыты согласия до начала операций, обязательный HF токен, порядок очереди, ошибка/сохранение результатов, отмена, параллельные операции, изоляция между экземплярами и восстановление состояния после перезапуска. Токен не попадает в preparation.json.

Реальный изолированный WebView2: отказ без галочки ничего не запускает и переводит фокус на согласие; после согласия подготовка готовой Whisper завершается в фоне после перехода к записям, с реальным пробным распознаванием. Окна 760 / 1024 / 1200 px при DPR 150% не имеют горизонтального переполнения. [Отчёт](evidence/zero-configuration/one-time-preparation.json), [подсказка после запуска](evidence/zero-configuration/setup-callout.png), [готовность](evidence/zero-configuration/setup-ready.png). Повторяемый focused driver: `windows-app/verify_preparation_ui.py`; требует отдельного помеченного тестового приложения, CDP и уже имеющейся Whisper, не разрешает скачивание новой модели.

Первоначальные попытки локального driver имели ошибки тестового workspace path / ожидания навигации CDP; успешный повтор сохранён отдельно. Новая полная сетевая установка всех выбранных компонентов, включая свежую GPU-среду и managed Ollama, в этом прогоне не выполнялась. Эти ограничения предыдущей приёмки сохраняются. Установленное приложение пользователя и его текущая подготовка не изменялись.

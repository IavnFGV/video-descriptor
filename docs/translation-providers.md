# Перевод локально или через Gemini

Перевод временно убран из UI записи и новых запусков конспекта. Отдельной вкладки,
галочки запуска, выбора режима, экспорта перевода и редактирования его промпта нет.
Будущее действие рядом с расшифровкой и выбор языка —
[issue #10](https://github.com/IavnFGV/video-descriptor/issues/10).
Сохранённые переводы, CLI, API и восстановление существующих заданий остаются.
Ниже описан сохранённый backend, а не доступный сценарий UI.

## Границы очистки backend

Срез 14.11.2026: `translate.py` — 241 строка; `translation_settings.py` — 134;
`postprocess.py` — 126; `prompt_settings.py` — 59 (полные файлы, включая пустые
строки, а не объём кода, который можно безопасно удалить). До новых UI-проверок
перевод упоминался в 29 тестовых модулях. Это не 29 отдельных тестов перевода:
среди них общие сценарии провайдеров, редакторов, экспорта, очереди и восстановления.

- `translate.py` сохраняется для CLI, старых заданий, кэша и повторов ошибок.
- `translation_settings.py` обслуживает общие подключения, ключи и defaults
  конспекта/статьи; удаление нарушит другие функции.
- `postprocess.py` обслуживает также конспект и статью; обработка старого
  `translate_after` нужна для совместимости существующей очереди.
- `prompt_settings.py` хранит несколько задач; сохранённые overrides перевода и
  черновики не очищаются при исключении пункта из UI.

Удалён ненужный frontend discovery моделей отдельной области перевода. Backend
и его regression tests не удаляются вместе с UI. Полное удаление требует отдельного
решения о CLI/API и миграции старых заданий, а не удаления общих сервисов.

## Сохранённые провайдеры

Общие подключения [Ollama](ollama-windows.md), [LM Studio](lmstudio-windows.md)
и Gemini доступны через **Инструменты → Настройки AI** и используются конспектом,
статьёй и другими операциями. Провайдеры конспекта и статьи выбираются в настройках действия.

Для Gemini создайте ключ в [AI Studio → API Keys](https://aistudio.google.com/api-keys).
Выберите проект с активным Billing для платного режима. Вставьте ключ в настройках,
сохраните и проверьте доступ кнопкой «Проверить доступ / получить модели».
Рекомендуемый начальный вариант: `gemini-3.5-flash-lite`; он проверен на наших
репликах. Список загружается через API Google. Доступность модели и её квота
зависят от проекта; присутствие в списке не гарантирует бесплатный вызов.

Поле Paid / Free не меняет billing Google. Оно фиксирует тип проекта пользователя.
Для Free требуется явное подтверждение условий обработки данных. API-ключ не
позволяет этому приложению проверить статус оплаты. Правила:
[условия Google](https://ai.google.dev/gemini-api/terms).

Ключ хранится в `.devcontainer/translation-settings.json` выбранного workspace,
исключён из Git и не возвращается UI. В Windows новое сохранение использует
DPAPI текущего пользователя; старый открытый ключ защищается при следующем
сохранении. На Linux файл создаётся с правами 0600, без шифрования.
`GEMINI_API_KEY` и старый `.env.gemini` поддерживаются как источники ключа.
HTTP-сервер запрещает получение скрытых файлов. Этот интерфейс предназначен
для локальной работы; авторизация пользователей и размещение в интернете
потребуют отдельного этапа разработки.

Новые задания фиксируют маршрут провайдера и модель в снимке настроек;
смена подключения не перенаправляет уже созданное задание на другой сервер.
Готовые результаты сохраняются. При переводе в облако отправляются промпт и текст реплик
с метками. Ответ проверяется; при потере меток блок разбивается. Ошибки ключа,
сети или квоты останавливают процесс с сохранением результатов.

В журнале результата сохраняются точные запросы без заголовка с ключом,
ответы и `usageMetadata`. В UI видны модель, токены и оценка цены запроса для
моделей с известным тарифом. Тарифы Standard от 2026-10-10 за миллион токенов:
3.5 Flash-Lite — $0.30/$2.50, 3.1 Flash-Lite — $0.25/$1.50,
3.8 Flash — $0.75/$3.75 до конца 2026 года (вход/выход включая рассуждения).
Это оценка по токенам, а не счёт Google. Для неизвестного тарифа цену не показываем.
[Актуальные тарифы](https://ai.google.dev/gemini-api/docs/pricing).

Gemini 3.5 Flash-Lite использует minimal thinking, 3.8 Flash — low,
остальные модели — свои настройки по умолчанию. Ответ — обычный текст с метками,
temperature=0, maxOutputTokens=4096. Модели из списка пока не все проверены:
при несовместимых параметрах сервис вернёт ошибку, а кэш останется доступен.

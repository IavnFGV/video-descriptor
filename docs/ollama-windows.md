# Ollama для Video Descriptor: установка в Windows

Ollama — отдельный сервер языковых моделей для перевода, конспектов и статей.
Распознавание Whisper и разделение по участникам от него не зависят.
Video Descriptor обращается к HTTP API. Установку, запуск, модели и обновления
Ollama пользователь выполняет самостоятельно.

## Установка и запуск

1. Скачайте установщик с [официальной страницы](https://ollama.com/download).
2. Запустите OllamaSetup.exe и завершите установку. Обычная установка выполняется
   в профиле пользователя. Для runtime и моделей нужно свободное место.
3. Откройте Ollama из меню «Пуск». Приложение работает в фоне, значок находится
   в области уведомлений. После установки откройте новое окно PowerShell.
4. Проверьте сервер:

```powershell
ollama --version
Invoke-RestMethod http://127.0.0.1:11434/api/version
```

Команда `ollama --version` проверяет CLI; ответ API подтверждает доступность сервера.
Если используете только CLI и сервер ещё не запущен, выполните `ollama serve`
в отдельном окне. Не запускайте второй сервер, когда фоновая Ollama уже работает.

## Установка модели вне Video Descriptor

Выберите текстовую модель в [официальной библиотеке](https://ollama.com/library),
прочитайте её требования и лицензию. Замените `<model-name>` точным именем и тегом:

```text
ollama pull <model-name>
ollama list
ollama run <model-name>
```

`pull` скачивает веса; `list` показывает установленные модели; `run` позволяет
вручную проверить ответ. Выход из интерактивного сеанса — `/bye`.
Video Descriptor не выполняет `pull` и не скачивает отсутствующую модель.

Приблизительные ориентиры для квантованных текстовых моделей (это оценки,
а не требования конкретной модели):

| Размер модели | Диск для весов | RAM или VRAM для работы |
|---|---|---|
| 1–3 млрд параметров | 1–3 ГиБ | 3–6 ГиБ |
| 7–9 млрд | 4–7 ГиБ | 8–16 ГиБ |
| 14 млрд | 8–12 ГиБ | 16–24 ГиБ |
| 30–32 млрд | 18–24 ГиБ | 24–48 ГиБ |

Квантизация, длина контекста и параллельные запросы существенно меняют расход.
Оставьте память Windows, Whisper и другим приложениям. Для самого runtime
также нужно несколько ГиБ. Наличие Intel GPU/NPU не доказывает поддержку модели;
фактическое размещение смотрите командой `ollama ps`. Предварительно загружать
модель в память для появления в списке Video Descriptor не требуется.

## Проверка API из PowerShell

```powershell
$endpoint = 'http://127.0.0.1:11434'
Invoke-RestMethod "$endpoint/api/version"
(Invoke-RestMethod "$endpoint/api/tags").models | Select-Object name, size
$body = @{ model = 'YOUR-INSTALLED-MODEL'; prompt = 'Reply: ready'; stream = $false } | ConvertTo-Json
Invoke-RestMethod "$endpoint/api/generate" -Method Post -ContentType 'application/json' -Body $body -TimeoutSec 180
```

В последней команде укажите имя из `ollama list`. Первый ответ может быть медленным
из-за загрузки весов в память.

## Настройки Video Descriptor

1. Откройте настройки AI → «Локальный AI (Ollama)».
2. Укажите `http://127.0.0.1:11434` или адрес вашего внешнего сервера.
   Разрешены HTTP/HTTPS без логина, пути, query и fragment.
3. Нажмите «Проверить и сохранить подключение». Проверьте статус и версию.
4. Нажмите «Обновить список», особенно после установки или удаления модели.
5. Выберите модель из списка **этого сервера**, назначение и «Сохранить модель».
6. Нажмите «Проверить генерацию». Успешное обнаружение модели и успешная генерация
   — отдельные проверки. Для конспекта и статьи Ollama выбирается в окне создания
   материала; сохранённая модель перевода используется переводом.

Смена адреса сразу очищает список и выбор. Приложение не выбирает другую модель
автоматически. Пустой список означает отсутствие моделей; ошибка подключения
означает недоступность сервера. Перед обработкой наличие выбранной модели проверяется снова.
Удалённый сервер получает текст обработки. Настройку доступа и защищённого соединения
выполняет его владелец; не публикуйте открытый Ollama API в интернете.

## Каталог моделей

По умолчанию используется каталог профиля `.ollama`. Чтобы хранить веса на другом
диске, откройте «Изменение переменных среды текущего пользователя» Windows,
создайте `OLLAMA_MODELS` со значением, например `D:\OllamaModels`, затем полностью
завершите Ollama через значок и запустите её из «Пуска» снова.
Старые веса автоматически не переносятся: сохраните исходную папку и проверьте
модели после самостоятельного переноса. Video Descriptor не перемещает и не удаляет их.

## Если не работает

- **Connection refused / сервер недоступен:** откройте Ollama из «Пуска», проверьте
  `/api/version`, адрес и порт. Для удалённого сервера проверьте сеть, firewall
  и настройку `OLLAMA_HOST` на стороне сервера.
- **Порт 11434 занят:** `Get-NetTCPConnection -LocalPort 11434 -State Listen`
  покажет слушающий процесс. Не завершайте неизвестный процесс; сначала установите,
  какой сервер уже работает. Если владелец сервера изменил порт, укажите его в настройках.
- **Нет моделей:** выполните `ollama list`, установите модель через `ollama pull <model-name>`
  на выбранном сервере и нажмите «Обновить список». Проверьте `OLLAMA_MODELS`.
- **Модель исчезла:** повторно обновите список и явно выберите существующую модель.
- **Недостаточно памяти / генерация завершилась ошибкой:** проверьте журналы Ollama,
  закройте ненужные приложения, используйте меньшую модель или меньший контекст.
  Проверка в настройках не гарантирует, что в память поместится длинная запись.
- **Медленно / таймаут:** первая загрузка занимает время; проверьте `ollama ps`,
  размер модели и свободную память. CPU обычно медленнее GPU. Повторите проверку
  после освобождения ресурсов, не запускайте множество запросов одновременно.
- **Некорректный ответ:** адрес должен вести именно к API Ollama, а не к странице
  веб-интерфейса. Для HTTPS проверьте сертификат на сервере.

Журналы Ollama находятся в `%LOCALAPPDATA%\Ollama`, в частности `server.log`.

## Обновление и удаление

Windows-версия Ollama самостоятельно получает обновления; примените «Restart to update»
из её значка либо установите актуальный официальный пакет. Выполняйте это отдельно
от Video Descriptor, когда обработка завершена.
Для удаления откройте настройки Windows → «Установленные приложения» → Ollama.
Предварительно сохраните нужные веса и уточните поведение собственного uninstaller;
особенно проверьте отдельный каталог `OLLAMA_MODELS`.
Обновление или удаление Video Descriptor не управляет Ollama и её моделями.

# Проверка устройств — Windows prototype 0.3

Дата: 17 октября 2026, та же реальная Windows-машина с Intel NPU/GPU/CPU.
Модели и драйверы не устанавливались/не менялись, облачные API не использовались.
Проверка использует уже установленный OpenVINO/GenAI 2026.4.1 и FP16 Whisper small.
Digest модели и точные версии записаны в [JSON-сводке](verification-devices.json).

## Реальные прогоны

Через `verify_devices.py` один и тот же MP4 20 s прошёл локальную очередь, извлечение
аудио, VAD, распознавание, сохранение результата и экспорт SRT:

| Настройка | Выбран / фактически использован | Время до проверки экспорта |
|---|---|---|
| CPU | CPU / CPU | 3.172 s |
| GPU | GPU / GPU | 3.250 s |
| NPU | NPU / NPU | 3.547 s |
| Auto | NPU / NPU | 3.188 s |

Модели предварительно загружены. Это единичные функциональные прогоны с API polling,
а не бенчмарк скорости: результаты не доказывают, что CPU быстрее NPU/GPU.
Во всех случаях проверены валидные конечные метки, один итоговый речевой сегмент,
SRT и неизменность плана задания при смене настройки сразу после upload.
Проверено присутствие событий settings/device/job/export в локальном журнале.

Отдельная проба worker на одном 20 s WAV без VAD: CPU load 1.250 s / inference 2.157 s,
GPU load 11.719 s / inference 0.984 s, по три сегмента с валидными временами.
SHA256 объединённого текста совпал между CPU и GPU; экспертной оценки текста не было.
Сырые результаты/медиа остаются локально в `windows-app/runtime/verification/`.

## Автоматические проверки и UI

174 tests passed, 1 skipped (право Windows symlink), Ruff и pip check проходят.
Проверены все восемь комбинаций доступности NPU/GPU/CPU, явный выбор без подмены,
отказ запуска, NPU → GPU и NPU → GPU → CPU после отказа runtime. Восстановление
не отправляет завершённые фрагменты повторно и сохраняет происхождение разных backend.
`end_ts=-1` сохраняется как диагностика и не вызывает переключение устройства.
Проверена защита от второй загрузки после timeout и исключение текста/секретов из событий.
В реальном прогоне найдена и исправлена гонка публикации job folder до manifest;
добавлен regression test. Это имитационные проверки отказов, физические адаптеры не отключались.

В браузере проверены выбор CPU, сохранение после reload, возврат Auto, отображение
готовности трёх устройств и истории. [Снимок интерфейса](windows-devices-preview.png).

## Что ещё не доказано

- CPU/GPU на длинных записях, нагрузка/память/энергопотребление и точность разных языков.
- GPU других производителей, другой Intel driver/model и реальные аппаратные отказы.
- Windows pyannote/диаризация и перевод/конспект через Ollama; выбор Whisper их не переключает.
- Установка без существующего benchmark runtime, ZIP/installer, upgrade/uninstall и чистая VM.

Следующий выпуск должен отдельно пройти эти проверки; этот отчёт их не заменяет.

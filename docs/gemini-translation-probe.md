# Отдельный замер перевода Gemini

Скрипт не меняет обработку лекции и не записывает облачные ответы в её кэш.
Берёт последние два завершённых текстовых запроса разных блоков, фиксирует выбор
в `output/gemini-translation-probe/samples.json`. Для нового набора используйте
другую папку `--output`. Промпт и исходный текст передаются без изменений.

1. В AI Studio откройте API Keys и создайте ключ в проекте с активной оплатой
   (Paid / Tier 1). Это свойство проекта, не параметр запроса. Скрипт не может
   определить billing по ключу; `--paid-project` означает, что это проверено вами.
2. В игнорируемом Git файле `.env.gemini` укажите `GEMINI_API_KEY=...`.
   Ключ передаётся только заголовком запроса и не записывается в отчёты.
3. Запустите из корня проекта:

```bash
python scripts/benchmark_gemini_translation.py \
  "output/2026-10-09 11-06-54-40be94a81a/requests" --run --paid-project
```

Без `--run` скрипт только готовит материал локально. По умолчанию модель
`gemini-3.5-flash-lite`: temperature=0, thinkingLevel=minimal, maxOutputTokens=4096,
ответ обычным текстом. Два последовательных вызова без автоматических повторов.
Повтор команды использует сохранённые ответы. Для нового платного замера выберите
новую папку `--output`.

Альтернативы: `--model gemini-3.1-flash-lite` (уровень рассуждений по умолчанию)
или `--model gemini-3.8-flash` (low). Сначала сравните один недорогой вариант.

Отчёт `output/gemini-translation-probe/gemini-3.5-flash-lite.html` показывает исходник,
локальный перевод и Gemini рядом. Проверка меток не оценивает смысл и качество:
проверьте термины, отрицания и полноту вручную. Локальное время взято из
`total_duration` ответа Ollama, облачное — время HTTP-вызова включая сеть.

Оценка USD по тарифам Standard от 2026-10-10 за миллион токенов:

| Модель | Вход | Выход, включая рассуждения |
| --- | ---: | ---: |
| 3.5 Flash-Lite | 0.30 | 2.50 |
| 3.1 Flash-Lite | 0.25 | 1.50 |
| 3.8 Flash | 0.75 | 3.75 |

Считается из фактических `usageMetadata`, без кэша, инструментов и Batch API.
Это оценка, а не счёт Google. Цены могут измениться; у 3.8 Flash указанные цены
действуют до конца 2026 года. Если ответ обрезан (`MAX_TOKENS`) или метки потеряны,
он всё равно мог быть оплачен. Скрипт сохраняет исходный ответ для проверки.

Источники: [тарифы](https://ai.google.dev/gemini-api/docs/pricing),
[ключи](https://ai.google.dev/gemini-api/docs/api-key),
[рассуждения](https://ai.google.dev/gemini-api/docs/thinking).

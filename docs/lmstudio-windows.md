# LM Studio для Video Descriptor: установка и подключение в Windows

LM Studio — отдельное приложение с локальным сервером моделей для перевода, конспектов и статей.
Распознавание Whisper и разделение по участникам от него не зависят.
Video Descriptor обращается к HTTP API Local Server. Установку LM Studio, загрузку моделей,
устройство и контекст пользователь настраивает самостоятельно.

## Установка и запуск

1. Скачайте установщик с [официальной страницы](https://lmstudio.ai/).
2. Установите LM Studio и запустите приложение. LM Studio остаётся работать на вашем компьютере;
   Video Descriptor не устанавливает, не запускает и не останавливает его.
3. В LM Studio загрузите текстовую языковую модель из каталога приложения, прочтите её требования
   и лицензию, затем загрузите модель в память. Video Descriptor не скачивает модель и не
   выбирает её за вас.
4. Откройте вкладку «Developer» → «Local Server» и включите Local Server. По умолчанию сервер
   доступен по адресу `http://127.0.0.1:1234`; API для Video Descriptor —
   `http://127.0.0.1:1234/v1`. При необходимости укажите другой локальный порт.
5. Если в LM Studio включена авторизация, скопируйте API-токен — он понадобится в настройках
   Video Descriptor.

## Проверка API из PowerShell

```powershell
$endpoint = 'http://127.0.0.1:1234/v1'
Invoke-RestMethod "$endpoint/models" | Select-Object -ExpandProperty data
$body = @{ model = 'YOUR-LOADED-MODEL'; messages = @(@{ role='user'; content='Reply: ready' }); stream = $false } | ConvertTo-Json
Invoke-RestMethod "$endpoint/chat/completions" -Method Post -ContentType 'application/json' -Body $body -TimeoutSec 180
```

Пример предназначен для сервера без авторизации. Если она включена, добавьте
заголовок `Authorization: Bearer <token>` к обоим запросам через `-Headers`;
не публикуйте токен или историю команд с его значением.

Укажите имя загруженной модели. Первый ответ может быть медленным из-за загрузки весов.
«Проверить модель» в настройках Video Descriptor выполняется в фоне; можно продолжать
пользоваться интерфейсом. Таймаут генерации — 600 секунд. После отмены текущий HTTP-запрос
ожидается до ответа или таймаута; приложение не останавливает LM Studio.

## Настройки Video Descriptor

1. Откройте настройки AI → вкладка «Локальный AI».
2. Выберите провайдера **LM Studio**.
3. Укажите `http://127.0.0.1:1234/v1` или адрес вашего локального сервера. Разрешены только
   loopback-адреса `http://` без логина, пути (кроме `/v1`), query и fragment.
4. Если в LM Studio включена авторизация, введите API-токен. Пустое поле сохраняет прежний токен.
5. Нажмите «Проверить подключение», затем «Обновить модели». Выберите модель из списка этого
   сервера и нажмите «Сохранить по умолчанию».
6. Нажмите «Проверить модель». Успешное обнаружение модели и успешная генерация — отдельные
   проверки. Для конспекта и статьи выберите LM Studio и модель в настройках соответствующего
   действия.

Смена адреса сразу очищает список и выбор. Приложение не выбирает другую модель автоматически.
Пустой список означает, что на сервере нет моделей; ошибка подключения означает недоступность сервера.
Перед обработкой наличие выбранной модели проверяется снова. Текст обработки отправляется на
локальный сервер LM Studio; настройку доступа выполняет пользователь.

## Устройство и контекст

Устройство, GPU offload и загруженный размер контекста настраиваются в LM Studio.
Приложение не переключает устройство и не управляет моделями LM Studio.
Автоматическое определение контекста требует данных о загруженном экземпляре из LM Studio.
Если сервер не предоставляет эти данные, отключите автоматический контекст и задайте размер в
настройках действия, исходя из настроек загрузки LM Studio. План использует консервативную
оценку размера текста; токенизатор не скачивается.
Метаданные загруженного экземпляра читаются через native `/api/v1/models`;
OpenAI-списка `/v1/models` для определения контекста недостаточно.

Токен в Windows защищён DPAPI текущего пользователя; браузер получает только признак его наличия.
Для запуска из командной строки также поддерживается `LM_STUDIO_API_TOKEN`. Токен не попадает в
задания, общий журнал и сохранённые payload запросов.
Список моделей не доказывает успешную генерацию: пустые/оборванные ответы отклоняются,
перевод обязан сохранить метки реплик, исходная расшифровка сохраняется.

## Если не работает

- **Connection refused / сервер недоступен:** включите Local Server в LM Studio, проверьте
  адрес и порт. Адрес должен вести именно к API LM Studio (`/v1`), а не к главному окну
  приложения.
- **Порт 1234 занят:** проверьте `Get-NetTCPConnection -LocalPort 1234 -State Listen`.
- **Нет моделей:** загрузите и загрузите в память модель в LM Studio, затем нажмите
  «Обновить модели» в Video Descriptor.
- **Модель исчезла:** повторите обновление списка и явно выберите существующую модель.
- **Ошибка контекста или памяти:** сократите предел ответа, используйте меньшую модель или
  разбейте конспект на части. Статья остаётся одним запросом по полной расшифровке.
- **Ошибка токена:** проверьте API-токен в настройках подключения.
- **Медленно / таймаут:** первая загрузка модели занимает время; проверьте свободную память
  и не запускайте множество запросов одновременно.

Официальные источники: [Local Server / OpenAI-совместимый API](https://lmstudio.ai/docs/developer/openai-compat),
[метаданные загруженных моделей](https://lmstudio.ai/docs/developer/rest/list).
Инструкция сверена 11.11.2026; требования конкретной версии смотрите у LM Studio.

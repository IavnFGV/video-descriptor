Открыть `prototype/index.html` в браузере или из корня рабочей копии:

```powershell
python -m http.server 8947 --bind 127.0.0.1 --directory design-system
```

Затем открыть `http://127.0.0.1:8947/prototype/`. Это отдельный статический макет;
он не запускает рабочие сервисы. Внизу раскрыть «Для согласования» для просмотра
очереди, обработки, ошибки, готового/пустого результата и набора компонентов.

На согласование: постоянная навигация, компактная форма, один основной action,
параметры распознавания внутри этапа, глобальные AI-подключения отдельно,
зелёный акцент/Segoe UI/40 px controls. До согласования production не переносить.

Гарантия текущего этапа:

```powershell
python scripts/check-ui-audit.py
```

Дальнейшие UI-правки следуют MASTER, page overrides и CONTRACTS. Source baseline
не обновлять механически для обхода проверки при редизайне.

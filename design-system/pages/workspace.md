# Библиотека, рабочее пространство и отчёты

Наследуют MASTER. На широком окне общая боковая навигация; до 800 px — строка.
При выбранной записи заголовок с названием показывается один раз. Список версий,
этапы и параметры остаются доступны с клавиатуры. Чтение/правка конспекта в iframe
скрывают только дублирующую оболочку отчёта. Standalone отчёт сохраняет её.

Реплика использует dialog шириной до 760 px; остальные диалоги — до 560 px.
Прокрутка внутри 90dvh. Несохранённые изменения подтверждаются вторым native
shared dialog с начальным фокусом на продолжении редактирования. Escape этого
подтверждения сохраняет правки. Ошибка API не закрывает редактор.

Shared foundations применяют компоненты также к динамическим controls без
перезаписи HTML-handler IDs. Geometry видео/iframe ограничена viewport;
большие transcripts и таблицы имеют собственную прокрутку. Стили CodeMirror
меняют внешнюю палитру и доступность controls, не реализацию редактора.

# Библиотека, рабочее пространство и отчёты

21.10.2026: владелец согласовал отдельный интерактивный прототип и внедрение в ветке
feat/unified-recording-workspace. Выбранная запись сразу открывает /create; прежний
native экран результата больше не является промежуточной страницей. Ширина рабочего
пространства занимает доступное окно; чтение ограничено 76ch. Слева одно видео и под
ним расшифровка, справа конспект. Кнопка над видео меняет положение: наверху на всю
ширину, оба текста ниже. До 1000px панели располагаются последовательно. Магнитик
рядом с кнопкой положения связывает временные метки и прокрутку; ручная прокрутка
приостанавливает следование и показывает «Вернуться к текущему моменту».
Варианты речи и конспекта имеют отдельные native select с пунктом нового запуска.
Настройки раскрываются в текущем рабочем месте; результат остаётся доступен.
Готовые детали обработки свёрнуты, активный прогресс и ошибки доступны отдельно.

Наследуют MASTER. На широком окне общая боковая навигация; до 800 px — строка.
При выбранной записи заголовок с названием показывается один раз. Список версий,
этапы и параметры остаются доступны с клавиатуры. Чтение/правка конспекта в iframe
скрывают только дублирующую оболочку отчёта. Standalone отчёт сохраняет её.

Реплика использует dialog шириной до 760 px; остальные диалоги — до 560 px.
Прокрутка внутри 90dvh. Несохранённые изменения подтверждаются вторым native
shared dialog с начальным фокусом на продолжении редактирования. Escape этого
подтверждения сохраняет правки. Ошибка API не закрывает редактор.

Shared foundations применяют компоненты также к динамическим controls без
перезаписи HTML-handler IDs. Geometry видео/iframe ограничена viewport;
большие transcripts и таблицы имеют собственную прокрутку. Стили CodeMirror
меняют внешнюю палитру и доступность controls, не реализацию редактора.

07.11.2026: строка реплики использует компактный native select без постоянной рамки; он назначает голос только текущей реплике. Пункт «Создать и назначить» регистрирует голос и назначает его здесь. Общая панель «Говорящие записи» переименовывает все реплики. Таймкод и правка имеют тихое оформление, остаются видимыми и доступны с клавиатуры.

07.11.2026: speaker-select использует field-sizing:content — ширина соответствует текущему имени, а не самому длинному пункту меню. Native arrow остаётся рядом с подписью.

07.11.2026: диаризация публикует diarization_progress {stage,label,completed?,total?,updated_at,stage_started_at} из реальных hooks pyannote. Parent сохраняет структуру в speech.json и live snapshot. На экране один текущий этап с SVG-кольцом: unknown total — вращение без aria-valuenow, известный положительный total — измеренный процент; при reduced-motion вращения нет. Длительность этапа и давность последнего события не объявляются ETA/heartbeat модели. Стандартная линейная полоса скрыта только на активной диаризации; завершение/ошибка убирают кольцо. Unique speaker counts до clustering не показываются.

07.11.2026: construction-model — native select с автоматическим /api/construction-models?provider=. Исходные IDs и API сохранены; construction-models datalist остаётся совместимым скрытым inventory. Refresh рядом с полем, модель не переключается молча. Список провайдера проверяется перед Save/Run; stale-response guard modelRequest, недоступная сохранённая модель показана и блокирует запуск. Черновик model сохраняется до асинхронного inventory.

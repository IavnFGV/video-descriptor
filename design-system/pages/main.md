# Главная / новая запись

Наследует MASTER без изменения токенов. `prototype/index.html` — демонстрация компоновки, не замена `windows-app/ui/index.html`.

При входе в production с `?job=` открыть выбранный результат, а не терять его ради формы. Первый запуск с incomplete setup показывает обязательные шаги; обычный запуск оставляет рабочую форму первой. File picker, title, language, speech-device и start сохраняют контракты CONTRACTS.md. Readiness может блокировать start, но объясняет причину рядом и предлагает конкретный шаг настройки.

Прототип имеет отдельные маршруты hash только для демонстрации, mock «Добавить пример» и ручной переключатель состояний. Demo кнопки не обращаются к backend, не запускают очередь и не скачивают модель. Реальная file selection локальна; передаются только имя/метаданные внутри страницы. Никаких fake success сообщений о настоящем распознавании.

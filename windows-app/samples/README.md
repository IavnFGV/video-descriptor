# Встроенные тестовые записи

Короткая синтетическая английская речь, подготовленная для тестирования этого
приложения. Личных записей и внешней музыки нет. Файлы распространяются на условиях
лицензии проекта. Ожидаемый текст (возможны различия пунктуации):

> This is a local transcription test. The blue train arrives at the station at nine.
> Please save this sentence as subtitles.

`speech-check.wav`: mono PCM16, 16000 Гц, около 9,1 секунды. Используется кнопкой
«Проверить на встроенной записи» после подключения и подготовки Whisper.
`speech-check.mp4`: та же речь с видеодорожкой для ручной проверки полного сценария
импорта видео, редактора и экспорта. Расположен рядом с WAV в `windows-app/samples`
в папке установленного приложения и в ZIP.

Проверка выполняет настоящее распознавание на выбранном устройстве. Наличие
записей не заменяет модель Whisper. Автоматического изменения или обрезки
выбранных пользователем файлов нет.

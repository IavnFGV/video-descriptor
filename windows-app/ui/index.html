Первоначальная настройка AI

1. Проверьте компоненты → 2. Подключите Whisper → 3. Подготовьте распознавание. Перевод, облако, OCR и диаризацию можно пропустить.

Подготовим приложение к работе

Проверяем установленную модель…

Подключите имеющуюся Whisper small FP16 в формате OpenVINO. Файлы останутся на месте. Проверка ничего не скачивает и не меняет модели.

Скачать проверенную модель Whisper

Требуются OpenVINO/GenAI 2026.4.1 (включены в установщик), около 550 МиБ на диске и CPU либо совместимый Intel GPU/NPU с драйвером. Существующие модели сохраняются.

После подключения нажмите «Подготовить распознавание» в панели готовности. Дополнительная короткая проверка выполняется только по вашей команде.

Перевод через Ollama

Если Ollama отсутствует: официальная инструкция https://ollama.com/download/windows (откройте в браузере). Установите Ollama и нужную модель, затем обновите список. Выберите уже установленную языковую модель. Ничего не скачивается. Ollama самостоятельно управляет устройством для перевода.

Gemini · необязательно

При обработке данные отправляются в облако Google. Возможны расходы и ограничения квоты. Проверка ниже запрашивает только список моделей, без видео и транскрипции. Ключ защищается учётной записью Windows (DPAPI).

Вернуться можно кнопкой «Настройка AI». Для локального распознавания достаточно Whisper, CPU и FFmpeg.

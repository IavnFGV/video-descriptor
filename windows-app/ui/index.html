Локальный AI (Ollama)

Перевод через Ollama

Ollama запускает локальные языковые модели для перевода и конспектов. По умолчанию используйте работающую Ollama на 11434. При отдельном выборе управляемой установки официальный Windows ZIP размещается в пользовательском каталоге приложения; права администратора не нужны.

Для этой версии поддерживаются только localhost, 127.0.0.1 и [::1]. Настройки и жизненный цикл внешнего сервиса остаются под вашим управлением.

Говорящие · условия доступа Hugging Face

Определение говорящих

Автоматически подготовим отдельное окружение и модель community-1. Системный Python не нужен. Требуется не менее 8 ГиБ свободного места; загрузка пакетов может занять несколько гигабайт. Распознавание остаётся в своём окружении.

Для community-1 требуется принять условия Hugging Face и предоставить токен чтения. Токен защищается Windows DPAPI; в отчёты не попадает.

Автоматический режим пробует видеокарту, затем процессор. Явно выбранное устройство не заменяется другим. Нейропроцессор (NPU) пока не поддерживается для определения говорящих.
